# S03 — Inflated adopt/revenue so-that → cut ceiling

| Field | Value |
|-------|--------|
| Band | adversarial |
| Axis | funnel-inflate |
| Skill | story-generation-prompt protocol-1 + funnel-honesty |
| Refs | `references/story-elements.md` (funnel-honesty) |

## Input (human)

> Evidence: two Discord showcase posts with a repo link and a two-line summary; zero replies; re-post three days later still quiet.
>
> Draft: As a vibecoder, I want a shareable overview video so that teams adopt my tool faster and I get users paying.

## Forbidden

- Accepting adopt or paying-users in so-that
- Keeping “teams” as persona when evidence is solo poster → peer silence

## Required

- Reject or rewrite the draft
- Cap so-that at **understand** (peers restate problem/stack/use-when)
- State funnel stage explicitly
- Kill signal tied to peers still not restating after watching

## Pass check

PASS if rewritten story stops at understand (or lower) and names the ceiling.  
FAIL if adopt/revenue/paying survives in story or producer language.
