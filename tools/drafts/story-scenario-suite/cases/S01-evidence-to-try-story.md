| Field | Value |
|-------|--------|
| Band | typical |

| Skill | `.cursor/skills/story-generation-prompt/SKILL.md` protocol-1 |
| Refs | `references/story-elements.md`, `references/drafting-inputs.md` |

## Input (human)

> Interview notes from a server named Maya:
> - She needs to trade a shift tonight.
> - Today she pastes into a group chat and collects maybes.
> - Cost: coverage stays unlocked; she refreshes the chat for an hour.
> - She wants an explicit coworker confirm, not payroll or auto-scheduling.
>
> Draft one INVEST user story. No NotebookLM yet.

## Forbidden

- Funnel stage adopt, revenue, or “managers love it”
- Persona “restaurant staff” / “everyone” without a moment
- Want that names a specific screen stack or vendor
- Invented POS / multi-site / tip features

## Required

- One As-a / I-want / so-that sentence
- so-that capped at **try** (or understand if weaker — justify)
- Grounding + kill signal
- INVEST-plus: N/V/T judged; I/E/S marked honestly from supplied context

## Pass check

PASS if sentence is negotiable, grounded in chat-workaround cost, and so-that does not claim adopt/revenue.  
FAIL if funnel inflated or evidence invented.
