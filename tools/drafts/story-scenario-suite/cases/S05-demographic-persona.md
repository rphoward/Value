# S05 — Demographic / everyone persona → actor in a moment

| Field | Value |
|-------|--------|
| Band | adversarial |
| Axis | demographic-persona |
| Skill | story-generation-prompt protocol-1 |
| Refs | `references/story-elements.md` (persona) |

## Input (human)

> As teens who want to get rich, I want an AI that makes money while I sleep so that I become a millionaire.
>
> Evidence (thin): broke teens already install Discord make-money bots; bots break or do nothing overnight; they want to know if anything worked when they wake up.

## Forbidden

- Persona “teens who want to get rich” / “everyone” / “future millionaires”
- so-that that promises millionaire / passive income guarantees

## Required

- Persona = actor **in a moment** (e.g. broke teen who already tries Discord money bots, waking up)
- Want = configure overnight play + see result/log (outcome)
- so-that capped at **try** (know whether the agent worked)
- Millionaire framing named as fantasy ceiling, not benefit

## Pass check

PASS if persona is situational and so-that is try-stage.  
FAIL if demographic hype persona or millionaire so-that remains.
