# Value map

Owner-locked refresh (2026-07-25) from the shipped Product-Spine pack — replaces Values-only dogfood map. Label each entry with its evidence kind: fact, inference, hypothesis, decision, or unknown.

## Offering

- (decision) Offering: **Product-Spine** — an installable Cursor skill pack that guides a vibecoded idea from value clarity through optional lean MVP scope to an honest marketable claim. Exclusion: not an autonomy coach, not a “make it go viral” video product, not a general marketing course.
- (fact) Included: (1) `/product-spine` guide-turn (phase, why, this-turn, come-back-when; claim lists saved note paths; re-entry names progress so far); (2) `/value` decision grill with `workproduct/` session memory and milestones; (3) `/lean-mvp` for honest MVP scope when needed; (4) `/story-generation-prompt` for one INVEST-plus sentence plus short NotebookLM Do-this (upload folder, Chat Box A, Video Box B); (5) peer Discord paste voice on north-star / upgrade posts (who + freeze + what you get — no feature laundry).


## Pain relievers

- (hypothesis / lived use) (1) Guide-turn + claim evidence handoff — stops “find the profile yourself” dump at the last door. (2) Mid-session value grill — shifts frame from code-only to who/job without abandoning the build. (3) Saved notes under `workproduct/` — decisions endure across chats. (4) Progress-so-far on spine re-entry — reduces amnesiac restart. (5) Short NotebookLM how-to — one upload plan, not essay forks. (6) Peer Discord paste voice — reduces freeze when saying why someone else would care.


## Gain creators

- (hypothesis) Thin and honest: (1) INVEST sentence + saved notes → peers can restate who/why (understand/try). (2) Discord paste voice → possible showcase replies if the claim is used. (3) Installable pack → adoption only if people run `/product-spine`. Not claimed as proven: competence from the grill alone, ambassador recognition, or video as the win.


## Fit links

- (inference) Install + `/product-spine` → try-stage use. Value grill + milestones → claim evidence without re-paste. Story skill → INVEST from those notes; NotebookLM optional and secondary. Progress-so-far → re-entry continuity. Gain links stay conditional — no direct promise of Discord traction.


## Orphan candidates

- (decision) None parked. Autonomy remains context for vibecoding, not a separate offering part. Standalone Values repo remains an install path for the value skill; Product-Spine is the intercalated journey pack.


## Differentiation

- (fact / inference) vs start-another-project / chase-bigger-model / polish-chrome: stays on the current build, asks outward-value questions, saves answers, and exits with an honest claim — not hype and not “spit vibecode into gold.” vs pitch-first tools: claim is drafted from saved notes after (or with) clarity, with funnel ceiling understand/try unless stronger evidence exists.


## Decisions

- (decision) Product center is the guided vibecode → valuable → claim path (Product-Spine), not a blurb-only micro-product.
- (decision) Funnel ceiling for current claim copy: **try** (install and run once on a real project). Engagement and video payoff remain hypotheses.
